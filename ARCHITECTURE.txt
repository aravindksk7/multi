XML COMPARISON ALGORITHM:
1. Parse XML → lxml.etree (handles malformed XML gracefully)
2. Normalize → remove whitespace, sort attributes
3. Build maps → group nodes by tag+identifier
4. Compare → recursive tree traversal with position matching
5. Generate XPath → human-readable location paths
6. Output → structured JSON with type annotations

DATABASE SCHEMA:
- Primary table: comparison_jobs
- Indexes on: id, status, created_at, suite_name, environment, run_id
- Composite indexes for common filter combinations
- JSON columns for flexible diff storage
- Timestamp tracking for audit trail
