What are OUCH/ITCH Protocols?

NASDAQ's OUCH and ITCH protocols are industry-standard messaging protocols for electronic trading systems. This module allows you to test protocol conformance and message handling:

OUCH Protocol

  • Enter Order: Submit new orders
  • Cancel Order: Request order cancellations
  • Replace Order: Modify existing orders
  • Order Accepted: Confirmations
  • Order Executed: Execution reports

ITCH Protocol

  • System Event: Trading status
  • Stock Directory: Symbol info
  • Add Order: Order book additions
  • Order Executed: Trade executions
  • Trade Messages: Non-cross trades
