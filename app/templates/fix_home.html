What is FIX Protocol?

The Financial Information eXchange (FIX) Protocol is an industry-standard messaging protocol used for real-time electronic communication of securities transactions. This module allows you to:

  • Send Orders: Create NewOrderSingle (D) messages for buy/sell orders
  • Cancel Orders: Request order cancellations
  • Track Messages: Monitor message status and history
  • View Details: Inspect raw FIX message content

Common Message Types

D - NewOrderSingle

Submit a new order

F - OrderCancelRequest

Request to cancel an order

0 - Heartbeat

Connection heartbeat

A - Logon

Session logon

💡 Quick Start:

Click "Send FIX Message" above to create a NewOrderSingle message. Fill in the required fields like symbol, side (1=Buy, 2=Sell), quantity, and price to send your first order.
